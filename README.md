# ARM — 로봇팔 3대 협업 프로젝트

로봇팔마다 독립된 라즈베리파이를 사용하며, 카메라 구성과 담당자가 다릅니다.
각 담당자는 자신의 장비 폴더에서 코드·설정·문서·산출물을 관리합니다.

## 폴더 구성

```text
ARM/
├── README.md
├── docs/                  # 통합 구성도, 통신 규칙, 연동 시험
├── common/                # 실제로 공유하는 코드
├── A1/                    # A1 담당자 작업 영역
│   ├── README.md          # 담당자, 장비 사양, 설치·실행·검증 안내
│   ├── src/               # 제어·카메라·영상 처리 코드
│   ├── config/            # 장비별 설정
│   ├── calibration/       # 장비별 보정값
│   ├── motion/            # 티칭 좌표, 동작 시퀀스
│   ├── hardware/          # 배선도, 장착도, 부품 목록
│   ├── scripts/           # 설치·실행 스크립트
│   ├── image/             # 장비 사진, 결과 캡처
│   ├── tests/             # 시험 코드, 검증 결과
│   └── deliverables/      # 개별 확정 산출물
├── A2/                    # A1과 동일한 구조
├── A3/                    # A1과 동일한 구조
└── deliverables/          # 전체 통합 보고서, 발표자료, 시연 링크
```

## 협업 규칙

- A1·A2·A3 담당자는 각자의 폴더에서 작업하고, 장비 README도 함께 갱신합니다.
- 장비별 카메라 코드·설정·보정값은 각 장비 폴더에 보관합니다.
- 공통으로 쓰는 코드만 `common/`에 두고, 변경 시 관련 담당자와 검토합니다.
- 장비 간 통신 규칙은 `docs/`에 기록하고 함께 검토합니다.
- 개별 산출물은 `A1~A3/deliverables/`, 전체 통합 산출물은 루트 `deliverables/`에 보관합니다.
- 비밀번호, 토큰, SSH 개인 키는 커밋하지 않습니다. 필요한 설정은 비밀값 없는 예시 파일로 공유합니다.
- 대용량 시연 영상은 외부 저장소 링크와 설명을 산출물 문서에 기록합니다.

## 산출물 기준

| 구분 | 산출물 |
|---|---|
| 장비별 | 코드, 설치·실행 안내, 장비 설정, 보정 자료, 배선도·부품 목록, 시험 결과, 시연 자료 |
| 통합 | 시스템 구성도, 통신 명세, 연동 시나리오, 통합 시험 결과 |
| 최종 제출 | 통합 보고서, 발표자료, 시연 링크, 요구사항별 완료 검증표 |

각 장비의 설치·실행 절차는 해당 README를 참고합니다. 현재 폴더 구조와 작성 양식만 준비되어 있으며, 실행 코드와 장비 정보는 담당자가 채워야 합니다.
